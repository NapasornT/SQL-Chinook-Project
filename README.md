# SQL Chinook Project

## Project Overview
This project analyzes the Chinook SQLite database using SQL queries executed in Python.

The project answers the following business questions:

- Top 10 best-selling tracks
- Country generating the most revenue
- Top-performing sales employee

## Technologies
- Python
- SQLite
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Structure

```
SQL-Chinook-Project/
│
├── Chinook_Sqlite.sqlite
├── SQL-Chinook-Project.ipynb
├── README.md
└── .gitignore
```

## How to Run

1. Clone this repository

```
git clone https://github.com/USERNAME/SQL-Chinook-Project.git
```

2. Install dependencies

```
pip install pandas matplotlib
```

3. Open

```
SQL-Chinook-Project.ipynb
```

4. Run all cells.

## Results

The project includes visualizations of

- Top Selling Tracks
- Revenue by Country
- Revenue by Employee
